# PreuSync Official Website (v1.0.0)

Sitio Web Oficial y Landing Page de la plataforma **PreuSync**, optimizada como **Static Site** para su despliegue en Render.

## 🚀 Características
- **Información Oficial**: Presentación de las características de la plataforma PreuSync (Horario escolar, comunidad, noticias, eventos y efemérides).
- **Descarga Directa de la APK**: Enlace directo a las versiones de la App Android.
- **Acceso Rápido al Panel Admin**: Enlace al panel web de administración (`https://preusync-admin.onrender.com`).
- **Diseño Responsive**: HTML5 + Tailwind CSS + Lucide Icons adaptado para dispositivos móviles, tablets y computadoras.
